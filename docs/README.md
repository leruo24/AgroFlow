**Why some files sit at the top of docs/:** we never edit a migration once it
has been applied, so any doc a migration cites by path stays exactly where it
is. `fao56-engine-report.md`, `finish-features-report.md` and
`OVERNIGHT_REPORT.md` are cited by 0027, 0036 and 0017. `drought-community.md`,
`irrigate-path.md`, `password-reset.md`, `translations-review.md`,
`audit/ui-contracts.md`, `audit/fix-report-2026-10-23.md` and
`ops/verify-migrations.sql` are cited by later migrations too. `Fao56.pdf` is
cited from `backend/AgroFlow.Domain/IrrigationControl/Agronomy/fao56-crop-knowledge.json`.
`reports/actionable/baseline.md` is read by a test, which also uses that folder
to find the repository root.

The admin Playwright HTML report, and the screenshots two specs
(`drought-community`, `location-picker`) take, are written to
`docs/test-evidence/`, which is git-ignored.
