**Why some files sit where they do:**
`fao56-engine-report.md`, `finish-features-report.md` and `OVERNIGHT_REPORT.md`
are cited by path from `supabase/migrations/` (0027, 0036 and 0017), which are
never edited after they are applied. `Fao56.pdf` is cited from the FAO-56
knowledge file in `backend/AgroFlow.Domain/Agronomy/`. `reports/actionable/baseline.md`
is read by a test, which also uses that folder to find the repository root.

Older development reports, the September orientation notes and the showcase
video project were removed on 10 Oct 2026 and are kept in the git tag
`archive/pre-tidy-2026-10-10`.
