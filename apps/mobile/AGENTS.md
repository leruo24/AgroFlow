# Expo HAS CHANGED

This app is on **Expo SDK 57** (`expo` ~57.0.21, React Native 0.86, React 19.2).

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before
writing any code. APIs move between SDKs — do not trust older answers or the
unversioned `/latest/` docs.

Expo packages are versioned to match the SDK (`expo-router` is `~57.0.x`, not
`~7.x`). Add native modules with `npx expo install <pkg>`, never plain
`npm install`, and run `npx expo install --fix` after bumping `expo`.
